# Руководство администратора

Админ-панель доступна по адресу `/admin` только пользователям с ролью
`ADMIN`. Для входа используйте учётную запись администратора.

!!! tip "Админ по умолчанию"
    `admin@gastronomiakomi.ru` / `Admin123!`
    (создаётся скриптом seed, смените пароль в продакшене!)

## Навигация

| Пункт меню | Назначение |
|---|---|
| **Дашборд** | Ключевые показатели платформы |
| **Мастер-классы** | Список, создание и редактирование |
| **Мероприятия** | Список, создание и удаление |
| **Блюда** | Каталог национальных блюд |
| **Пользователи** | Роли и блокировка аккаунтов |

## Дашборд

Страница `/admin` показывает:

- общее количество пользователей, мастер-классов, мероприятий и блюд;
- количество записей на мастер-классы и мероприятия;
- **выручку** (сумма цен записей) и среднюю цену мастер-класса;
- **популярные мастер-классы** — топ по количеству записей;
- динамику роста пользователей (процент за период).

## Управление мастер-классами

### Создание

1. В разделе «Мастер-классы» нажмите **«+ Создать»**.
2. Заполните форму:
   - **Название** и описание (краткое для карточки, полное для страницы);
   - **дата и время** проведения;
   - **длительность** (минуты);
   - **стоимость** (0 — бесплатно);
   - **максимум участников**;
   - связанное **блюдо** и **место проведения**;
   - **статус**: `ACTIVE` — виден всем, `DRAFT` — черновик, `ARCHIVED` — архив.

### Статусы

- `ACTIVE` — публикуется в каталоге, доступна запись;
- `DRAFT` — скрыт из публичного каталога;
- `ARCHIVED` — скрыт, данные сохраняются.

### Удаление

Кнопка **«Удалить»** в таблице. Действие необратимо — вместе с мастер-классом
удаляются записи пользователей на него.

## Управление мероприятиями

Аналогично мастер-классам: создание через **«+ Создать»**, поля — название,
описание, дата начала, локация, стоимость, максимум посетителей и статус.
Удаление доступно из таблицы.

## Блюда

Раздел показывает каталог блюд: название (включая название на языке коми),
категорию, сложность, время приготовления и число связанных заведений.

## Пользователи

В разделе **«Пользователи»** можно:

- искать пользователей по имени или email;
- **менять роль**: `USER` → `MODERATOR` → `ADMIN` (выпадающий список);
- **блокировать/разблокировать** аккаунты (кнопка в строке).

!!! warning "Ограничения"
    Заблокированному пользователю вход в систему запрещён.
    Администратора нельзя заблокировать самому себе.

## Безопасность

- Все запросы к API требуют Bearer JWT-токен;
- refresh-токены хранятся в БД и отзываются при выходе;
- rate limiting: `POST /auth/*` — 10 запросов / 15 минут;
- пароли хешируются `bcrypt` (12 раундов).
