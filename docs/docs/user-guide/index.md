# Руководство пользователя

Платформа «Гастрономия Коми» позволяет изучать национальную кухню,
записываться на мастер-классы и участвовать в мероприятиях.

## Регистрация и вход

1. Нажмите **«Регистрация»** в шапке сайта.
2. Укажите имя, email и пароль (минимум 8 символов).
3. После регистрации вы автоматически войдёте в систему.

Для входа используйте **«Войти»** и свои данные.

!!! info "Требования к паролю"
Минимум 8 символов, обязательно наличие букв и цифр. Проверка выполняется
и в браузере до отправки формы, и на сервере.

!!! warning "Демо-доступ"
Тестовые аккаунты в открытой документации не публикуются — они указаны
в закрытой заметке для разработчиков `DEVELOPER_NOTES.md`.

## Каталог блюд

- Откройте раздел **«Блюда»** в меню.
- Используйте **поиск** по названию и **фильтр по сложности**.
- На странице блюда вы найдёте описание, историю, рецепт, время
  приготовления и список заведений, где блюдо можно попробовать.
- Если по блюду проводятся мастер-классы, они показаны внизу страницы.

## Мастер-классы

### Поиск и фильтры

В разделе **«Мастер-классы»** доступны:

- поиск по названию;
- фильтр по максимальной цене;
- пагинация.

### Запись на мастер-класс

1. Откройте карточку мастер-класса и нажмите **«Подробнее»**.
2. Проверьте дату, место, стоимость и количество свободных мест.
3. Нажмите **«Записаться»** и подтвердите бронирование.

Запись доступна только авторизованным пользователям.

!!! warning "Ограничения"
Записать можно максимум **2 мастер-класса одновременно**.
Один мастер-класс нельзя забронировать повторно.

### Отмена записи

Отменить запись можно в **«Личном кабинете»** — нажмите **«Отменить»**
у нужной записи. Статус изменится на «Отменена».

## Мероприятия

- Раздел **«Мероприятия»** показывает фестивали и события.
- На странице мероприятия нажмите **«Участвовать»** и подтвердите.
- Участие можно отменить в личном кабинете.

## Личный кабинет

Раздел `/profile` содержит:

- ваши данные (имя, email, роль);
- **Мои записи на мастер-классы** — список записей со статусами
  («Подтверждена», «Отменена», «Завершена»);
- **Мои мероприятия** — список событий с возможностью отмены.
