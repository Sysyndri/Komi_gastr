# О платформе «Гастрономия Коми»

**«Гастрономия Коми»** — цифровая платформа для популяризации национальной
кухни Республики Коми. Платформа объединяет:

- **каталог блюд** — национальные рецепты с историей и техниками приготовления;
- **каталог заведений** — рестораны и кафе, где можно попробовать блюда коми;
- **мастер-классы** — практические занятия по приготовлению блюд;
- **мероприятия** — гастрономические фестивали и события региона.

## Возможности

| Возможность | Описание |
|---|---|
| Поиск и фильтрация | Блюда по сложности, мастер-классы по цене, полнотекстовый поиск |
| Запись на мастер-классы | Онлайн-бронирование мест с подтверждением и отменой |
| Участие в мероприятиях | Регистрация на фестивали и события |
| Личный кабинет | История записей и их статусы |
| Админ-панель | Управление контентом, пользователями и статистика |
| Интерактивная карта | Заведения национальной кухни на Яндекс.Картах |

## Технологии

- **Backend:** Node.js, Express, Prisma ORM, PostgreSQL, JWT-аутентификация, Swagger.
- **Frontend:** Next.js 14, React 18, TypeScript, TailwindCSS, TanStack Query.
- **Инфраструктура:** Docker Compose, GitHub Actions (CI/CD), Playwright (E2E).

## Структура монорепозитория

```
/
├── backend/          # REST API + тесты (coverage ≥ 80%)
├── frontend/         # Веб-приложение + тесты (coverage ≥ 70%)
├── docs/             # Данная документация (MkDocs)
└── docker-compose.yml
```

## Быстрый старт

```bash
cp .env.example .env
docker-compose up --build
```
